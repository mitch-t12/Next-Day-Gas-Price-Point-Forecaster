# Next-Day-Gas-Price-Point-Forecaster
Forecast next-day gas prices using historical pricing, market indicators, and operational inputs.

## Techologies
Python\
Pandas\
NumPy\
Scikit-learn\
Selenium\
Excel\
VS Code

## Methodology
Scrape weather, power, and capacity data\
Retrieve local historical pricing data\
Aggregate market indicators\
Perform regressions : Decision Tree, Random Forest, Linear\
Generate next-day forecasts\
Compare forecast error against historical averages

## Skills Demonstrated
Time series forecasting\
Data preprocessing\
Statistical modeling\
Machine learning\
Feature engineering\
Market analytics
